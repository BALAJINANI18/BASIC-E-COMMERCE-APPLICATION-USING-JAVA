# 🛒 E-Commerce Management System | Core Java

A console-based E-Commerce Management System developed using **Core Java and Object-Oriented Programming (OOP)** concepts. This project simulates a real-world online shopping experience where customers can register, log in, browse products, manage their shopping carts, and place orders.

## 🚀 Project Overview

The application provides an interactive shopping experience through a menu-driven console interface. Customers can explore available products, select items, manage quantities, view cart totals, and complete checkout.

The primary objective is to demonstrate practical implementation of Java fundamentals and OOP principles through a real-world application.

## ✨ Features

- 👤 **Customer Registration:** Register using name, email, and password.
- 🔐 **Customer Login:** Authenticate registered customers.
- 🛍️ **Product Catalog:** Browse available products with prices and stock.
- 🔎 **Product Selection:** Select products using unique product IDs.
- 🛒 **Shopping Cart:** Add products and manage quantities.
- 💰 **Price Calculation:** Automatically calculate item totals and grand total.
- 📦 **Inventory Management:** Validate available stock and update inventory after checkout.
- 🧾 **Order Management:** Generate order IDs and view order history.
- ⚠️ **Exception Handling:** Handle invalid numerical inputs.

## 🧠 OOP Concepts Implemented

This project demonstrates the following Object-Oriented Programming concepts:

- **Encapsulation:** Protecting data using private variables and getter methods.
- **Abstraction:** Exposing essential operations while hiding internal implementation details.
- **Classes & Objects:** Representing real-world entities such as customers, products, and orders.
- **Constructors:** Initializing objects with appropriate values.
- **Association:** Connecting shopping carts with cart items and products.

## ⚙️ How to Run the Project

**Prerequisites:**
- Java JDK 8 or above.
- IntelliJ IDEA / Eclipse / VS Code.

**Steps:**

1. Clone this repository:

```bash
git clone https://github.com/BALAJINANI18/BASIC-E-COMMERCE-APPLICATION-USING-JAVA.git
```

2. Open the project in your preferred Java IDE.

3. Navigate to `Main.java`.

4. Compile and execute:

```bash
javac Main.java
java Main
```

5. Follow the interactive console instructions to register, log in, and start shopping!
